# 实验3 CSS布局实战——导航菜单
Web应用开发技术实验，仅编写CSS，不修改原有HTML结构，外部CSS文件通过link标签引入。

## 实验功能
1. 一级导航菜单：基于table标签实现水平导航，黑底白字，鼠标悬停背景变为红色。
2. 二级下拉导航菜单：“欢迎访问湖南文理学院”文字和导航链接在同一行；二级子菜单默认隐藏，鼠标悬浮一级菜单项时显示下拉菜单，悬浮菜单项背景变红。

## 运行环境
VS Code + Live Server插件
Chrome浏览器

## 使用方法
1. 使用Live Server打开 `一级菜单.html`，查看一级水平导航效果。
2. 使用Live Server打开 `二级菜单.html`，查看带下拉的二级导航效果。
> 样式存放在 s.css，页面通过link标签引入该外部样式表。

## 技术要点
link标签引入外部CSS样式文件
后代选择器、伪类选择器的使用
盒模型padding控制元素内边距
flex布局实现元素同行水平排列
position:relative + position:absolute 完成二级下拉菜单定位
hover伪类实现鼠标悬浮交互效果
使用三位简写十六进制颜色代码 #000、#fff、#f00
