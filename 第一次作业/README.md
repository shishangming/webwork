# 个人简介网页
## 作业内容
制作个人简介静态网页页面。
## 使用到的标签
`<!DOCTYPE html>`、`<html>`、`<head>`、`<meta>`、`<title>`、`<body>`、`<h1>`、`<h2>`、`<p>`、`<strong>`、`<em>`、`<hr>`、`<img>`、`<br>`、`<a>`。

## 遇到的困难及解决方法
1. 困难：Git命令不熟悉，执行命令时容易把两行写在同一行导致报错。
解决方法：一行一行输入git命令，不要一次性粘贴多条命令。

2. 困难：一开始不清楚HTML标签规范。
解决方法：参考实验要求，标签全部小写，属性使用双引号，代码缩进。

3. 困难：本地图片加载失败、原图尺寸过大。
解决方法：将`sjm.jpg`放到网页项目同一个文件夹，使用相对路径引用图片；给img标签添加width属性限制图片宽度，解决图片太大撑开页面的问题。
